# Support

GeniaFirewall is an open-source project. Public support works best when reports are reproducible and contain only the information needed to investigate the problem.

## Where to ask

- **Bug:** open a Bug report Issue.
- **Compatibility result:** use the Compatibility report template.
- **Feature idea:** use the Feature request template.
- **Security vulnerability:** do not use a public Issue; follow [SECURITY.md](SECURITY.md).

## Before opening an issue

Please include the GeniaFirewall version, Windows version, backend, global mode, app rule profile, and short reproduction steps.

Do not paste full unrelated logs. Remove usernames, credentials, personal paths, private keys, and unrelated network endpoints.

For testing guidance see [TESTING.md](TESTING.md) / [TESTING_RU.md](TESTING_RU.md).
