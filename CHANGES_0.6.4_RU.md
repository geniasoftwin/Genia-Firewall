# Изменения GeniaFirewall 0.6.4

## Quick Rules

- `EnableAll`, `OutgoingOnly`, `DisableAll`, `Ask` теперь имеют отдельные обработчики и сохраняемый профиль.
- В колонке статуса отображается выбранная политика, а не только общее `Разрешено/Заблокировано`.
- Активное быстрое правило отмечается галочкой в контекстном меню.
- `IncomingOnly` оставлен видимым, но выключен до реализации inbound WFP; tooltip объясняет причину.
- `EnableAll` сопровождается пояснением, что в 0.6.4 самостоятельный backend пока outbound-only.

## Временный доступ

- Добавлено контекстное меню `Временный доступ`.
- `Разрешить на 10 минут`.
- `Разрешить до закрытия приложения` — только если EXE сейчас запущен.
- Временные решения по-прежнему fail-closed после завершения/перезапуска и не превращаются в постоянный Allow при экспорте.

## UI / данные

- Quick Rule profile сохраняется в `apps.json` и portable export/import.
- Старые 0.6.3 записи без нового поля остаются совместимыми (`Default`).
- Поиск учитывает локализованный статус/профиль.
- Свойства приложения показывают выбранное быстрое правило.

## Версии

- UI / Service / Protocol / manifests: `0.6.4.0`.
- IPC protocol: v7 (`GeniaFirewall.Service.v7`).
