# Privacy policy

## Runtime data

GeniaFirewall does not include developer analytics, advertising, cloud accounts, remote management, automatic crash uploads, or background update checks. It does not send firewall rules, executable paths, connection endpoints, logs, settings, or other runtime data to GeniaSoftWin or SignPath.

The application processes network metadata locally to enforce and display firewall policy. Portable settings, rules, backups, and UI logs are stored in the `Data` directory beside `GeniaFirewall.exe`. Service policy and service logs are stored under `%ProgramData%\GeniaFirewall` with administrative ACL protection. Files are exported only when the user explicitly chooses an export operation.

## Reverse DNS

The optional **Show host names for TCP (reverse DNS)** setting asks the Windows-configured DNS resolver for a host name associated with a remote IP address. This can disclose that IP address to the DNS resolver selected by Windows or the network administrator. Reverse DNS can be disabled in GeniaFirewall settings; firewall enforcement does not depend on it.

GeniaFirewall does not otherwise initiate Internet communication on behalf of the developer. Network traffic generated by applications on the computer remains subject to the rules selected by the user.

## Code-signing service

Official release binaries may be submitted by the project build pipeline to SignPath for malware scanning, provenance verification, and Authenticode signing. Release artifacts contain program code and version metadata, not user runtime data. [SignPath's privacy policy](https://signpath.io/privacy-policy) applies to that build-time service.

## Removing local data

Use **Settings → WFP system service → Deactivate** before removing GeniaFirewall. After the service is removed and the application is closed, delete the portable directory to remove user rules, settings, backups, and UI logs. An administrator may also remove remaining GeniaFirewall service logs under `%ProgramData%\GeniaFirewall` if they are no longer needed for diagnostics.

# Политика конфиденциальности

GeniaFirewall не содержит аналитики разработчика, рекламы, облачных учётных записей, удалённого управления, автоматической отправки сбоев или фоновой проверки обновлений. Правила, пути EXE, сетевые адреса, журналы и настройки обрабатываются и хранятся локально и не отправляются GeniaSoftWin или SignPath.

Необязательная настройка **«Показывать имена узлов для TCP (reverse DNS)»** обращается к DNS-resolver, настроенному в Windows. При этом resolver может получить проверяемый удалённый IP-адрес. Reverse DNS можно отключить в настройках; enforcement от него не зависит.

SignPath получает только собранные release-артефакты для проверки происхождения, антивирусного анализа и Authenticode-подписи. Пользовательские runtime-данные в эти артефакты не входят.

Для удаления локальных данных сначала деактивируйте системную WFP-службу в настройках, закройте GeniaFirewall, затем удалите portable-каталог. Оставшиеся диагностические журналы в `%ProgramData%\GeniaFirewall` при необходимости удаляются администратором.
