# Установка, первый запуск и удаление

[English](INSTALLATION.md) · [FAQ](FAQ_RU.md)

**Сначала уточните версию.** В **0.7.3 Stable** и тестовой **0.7.4 RC** разные процедуры установки и удаления службы. 0.7.4 RC ещё не Stable.

## Подготовка

- Windows 10/11 x64; для WFP-службы нужны административные права и подтверждение UAC.
- Скачивайте архив из [официальных Releases](https://github.com/geniasoftwin/Genia-Firewall/releases) либо из явно указанного RC-артефакта.
- Проверяйте SHA-256 нужного скачанного файла. Пример PowerShell (замените имя файла):

~~~powershell
Get-FileHash -Algorithm SHA256 -LiteralPath ".\GeniaFirewall-release.zip"
~~~

Сравните хеш с опубликованным значением. Совпадение проверяет файл **относительно опубликованного хеша**, но не доказывает личность издателя. RC может быть без Authenticode-подписи. Не проводите первый тест firewall на удалённой машине без локального доступа (RDP/VPN можно потерять).

## Установка 0.7.3 Stable — отдельная служба

1. Распакуйте соответствующий архив Stable в локальную папку.
2. Найдите **GeniaFirewall.Service.exe** и **install-service.cmd** в распакованной/publish-сборке.
3. Запустите **install-service.cmd от имени администратора**, дождитесь “Service installed and started.”
4. Скрипт размещает службу в `%ProgramFiles%\GeniaFirewall\Service` и настраивает `GeniaFirewallService` для LocalSystem с зависимостью BFE.
5. Запустите **GeniaFirewall.exe** из portable-папки.
6. В **Настройках** выберите **GeniaFirewall WFP**, если нужны входящие и исходящие app-правила, и проверьте состояние backend/службы.
7. Начинайте с глобального режима **Нормальный** и назначайте доступ осознанно.

## Установка 0.7.4 RC — встроенная служба / один пользовательский EXE

1. Распакуйте **GeniaFirewall.exe** из RC-архива в portable-папку, не запускайте прямо из ZIP.
2. Запустите EXE. При включении или активации службы в **Настройки → Системная служба WFP** подтвердите UAC, если система запросит.
3. Программа извлекает встроенную службу в `%ProgramFiles%\GeniaFirewall\Service` и до работы WFP проверяет SHA-256, защищённые ACL, SCM configuration и IPC identity.
4. Убедитесь, что служба активна, выберите backend **GeniaFirewall WFP** и глобальный **Нормальный** режим.
5. Для LAN-программы с передачей в обе стороны нужен явный профиль **Разрешить всё / EnableAll**; **Только исходящие** не открывает inbound.
6. Перезапустите UI/Windows и проверьте сохранение правил/backend.

В 0.7.4 RC предусмотрено обновление embedded service с rollback. Скрипты ручной установки из 0.7.3 не относятся к этой схеме. **0.7.4 Stable нельзя выпускать до завершения Windows-тестирования и Authenticode-подписи.**

## Проверка службы

~~~powershell
Get-Service -Name GeniaFirewallService -ErrorAction SilentlyContinue
~~~

Сама по себе работающая Windows-служба ещё не доказывает, что WFP policy успешно применена. Дополнительно смотрите backend, состояние службы и WFP diagnostics в программе.

## Безопасное удаление 0.7.4 RC

1. При необходимости выключите **Автозагрузку с Windows** в Настройках и сохраните.
2. Если правила нужны — заранее экспортируйте конфигурацию.
3. Откройте **Настройки → Системная служба WFP → Деактивировать**. Дождитесь успешной проверки пустого WFP runtime и перехода в Compatibility.
4. Если действие завершилось ошибкой, **не удаляйте защищённую службу вручную**; сохраните диагностику.
5. Выберите **Выход** в трее (крестик главного окна может лишь прятать приложение).
6. Удалите portable-папку с `Data`, если не нужны настройки, backup и UI-журналы. Остаточные служебные данные/логи в `%ProgramData%\GeniaFirewall` администратор может удалить после подтверждения удаления службы.

## Безопасное удаление 0.7.3 Stable

1. Выключите автозапуск в Настройках и выйдите через трей.
2. Запустите **uninstall-service.cmd от имени администратора** из соответствующего комплекта 0.7.3.
3. Дождитесь остановки и удаления службы; dynamic WFP-фильтры освобождаются при завершении сессии службы.
4. Проверьте `Get-Service -Name GeniaFirewallService -ErrorAction SilentlyContinue`: после полного удаления службы быть не должно. Иногда SCM ждёт закрытия дескрипторов или перезагрузки.
5. Удалите portable-папку. **Скрипт 0.7.3 не удаляет автоматически** persisted state в `%ProgramData%\GeniaFirewall\Service`; удаляйте его вручную лишь после проверки, что служба отсутствует.

**Не отключайте Microsoft Defender Firewall и не очищайте посторонние WFP-фильтры** ради удаления GeniaFirewall.

При проблемах смотрите [Диагностику](TROUBLESHOOTING_RU.md).
