- Capture a **real build** and state its version; do not label a mockup as a screenshot / снимок должен быть настоящим с указанием версии.
- Remove usernames, executable paths, public/private IPs, DNS names, tokens and personal notifications / скрыть учётные записи, пути, IP, DNS, токены, личные уведомления.
- Use a test environment or synthetic application names if possible / желательно тестовая среда.
- Prefer clear PNGs with short captions in EN/RU / предпочтительны PNG и подписи на обоих языках.
