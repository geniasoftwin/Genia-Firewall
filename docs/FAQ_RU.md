# Частые вопросы

[English](FAQ.md)

**GeniaFirewall — open source?** Да, исходники доступны по [GPL-3.0-only](../LICENSE): можно изучать, тестировать, форкать и улучшать в рамках лицензии.

**Какие версии Windows?** Windows 10/11 x64. Текущая WPF/.NET 10 сборка не предназначена для Windows 7.

**Почему UAC?** WFP backend использует привилегированную Windows-службу. Установка/активация и защищённая конфигурация требуют прав администратора.

**Установка Stable и RC одинаковая?** Нет. 0.7.3 Stable — ручной `install-service.cmd`, 0.7.4 RC — встроенная служба в одном пользовательском EXE. См. [Установка](INSTALLATION_RU.md).

**Надо выключать Microsoft Defender Firewall?** Нет. GeniaFirewall применяет WFP или Windows Firewall backend, Defender отключать не нужно.

**«Разрешить всё» открывает входящие LAN?** Явный app-профиль **EnableAll** открывает inbound+outbound в **GeniaFirewall WFP**. В Compatibility app-правила outbound-only.

**Почему старое «Разрешено» стало «Только исходящие»?** Legacy/default права могут сохраняться как outbound-only, чтобы не расширять их молча. Проверьте нужный доступ и явно выберите Разрешить всё.

**Ask удерживает первое соединение до ответа?** Нет. Для kernel-held pre-connect Ask нужен WFP callout driver.

**RC подписан?** Нельзя считать его подписанным без проверки. Для 0.7.4 Stable подписи Service и UI обязательны.

**Логи отправляются разработчику?** Автоматическая аналитика/выгрузка логов не предусмотрена. Необязательный reverse DNS может обращаться к DNS resolver Windows. См. [Приватность](../PRIVACY.md).

**Как полностью удалить?** Сначала деактивация WFP-службы (0.7.4 RC) или соответствующий uninstall-скрипт (0.7.3 Stable), затем выход и удаление portable-папки. См. [Установка и удаление](INSTALLATION_RU.md).
