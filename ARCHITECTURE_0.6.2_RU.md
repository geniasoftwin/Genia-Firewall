# GeniaFirewall 0.6.2 — архитектура Immediate Quarantine

## Цель

Не допускать ситуации, когда пользователь удаляет разрешённое правило у уже работающей программы, а удаление WFP-фильтра на несколько секунд возвращает ей свободный доступ в сеть.

## Del для работающего EXE

```text
Allow / Block
    ↓ Del
проверка: WFP + Normal + защита ВКЛ + EXE запущен
    ↓
Access = Ask
    ↓
ApplyFirewallState()
    ↓
GeniaFirewall.Service
    ↓
ALE_AUTH_CONNECT V4/V6
ASK-BLOCK (TCP/UDP)
    ↓
persist / refresh UI
    ↓
prompt
```

Критическое правило: WFP policy применяется **до** сохранения базы, обновления UI и создания prompt. Если применение WFP завершается ошибкой, прежнее решение восстанавливается.

## Del для остановленного EXE

Для неработающего приложения сохраняется прежняя семантика: запись и правило удаляются. При следующей обнаруженной сетевой активности приложение снова рассматривается как неизвестное.

## Ограничение

User-mode watcher всё ещё является источником обнаружения полностью нового EXE. Поэтому 0.6.2 гарантирует немедленный fail-closed при сбросе решения для уже известного и работающего процесса, но не гарантирует остановку самого первого пакета абсолютно нового процесса. Для этого запланирован WFP callout driver.
