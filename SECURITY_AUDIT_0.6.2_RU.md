# GeniaFirewall 0.6.2 — security audit notes

## Улучшено

- `Del` для работающего EXE в Normal/WFP больше не вызывает временное снятие защиты.
- Сначала устанавливается `ASK-BLOCK`, затем сохраняется состояние и показывается prompt.
- `Позже` и закрытие prompt крестиком оставляют `Ask`, следовательно WFP-блок сохраняется.
- Ошибка применения WFP приводит к rollback прежнего Allow/Block.
- IPC поднят до v5 для исключения случайного подключения UI 0.6.2 к старой службе.

## Не закрыто

- Полностью новый EXE всё ещё обнаруживается user-mode watcher-ом после возникновения сетевой активности.
- Нет inbound enforcement.
- Нет kernel callout / `FwpsPendOperation0`, поэтому истинный pre-connect Ask пока отсутствует.
- При отключённой настройке Immediate Quarantine `Del` работает по старой семантике.

## Рекомендация для тестов

Microsoft Defender Firewall держать включённым, кроме коротких контролируемых A/B тестов. Для 0.6.2 проверять отдельно, что при Del на работающем браузере интернет исчезает до закрытия prompt и возвращается только после Allow.
